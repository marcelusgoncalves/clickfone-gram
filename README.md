# ClickFone GRAM

Landing page para a plataforma **ClickFone** - Solução de Telefonia VoIP em Nuvem da Memória RAM Solutions.

## 🚀 Quick Start

Este é um projeto bootstrap com [Next.js](https://nextjs.org/) via [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

### Desenvolvimento

```bash
npm run dev
yarn dev
pnpm dev
bun dev
```

Abra [http://localhost:3000](http://localhost:3000) com seu navegador para ver o resultado.

Você pode começar editando `app/page.tsx`. A página auto-atualiza quando você edita o arquivo.

### Produção

```bash
npm run build
npm run start
```
